# HAVEN HOTEL

Website đặt phòng khách sạn demo.

Đề tài:
Phân tích nghiệp vụ phần mềm

## 1. Công nghệ

Frontend:

- HTML
- CSS
- JavaScript

Backend:

- Python
- Flask

Email:

- Gmail SMTP

Lưu dữ liệu:

- LocalStorage

## 2. Chức năng khách hàng

- Xem phòng
- Lọc phòng
- Sắp xếp theo giá
- Tìm phòng
- Xem chi tiết phòng
- Đặt phòng
- Tính tiền tự động
- Kiểm tra trùng lịch
- Hủy phòng
- Xem lịch sử đặt phòng
- Gửi email xác nhận

## 3. Chức năng quản trị

- Xem tổng số phòng
- Xem phòng trống
- Xem số đơn đặt phòng
- Xem doanh thu
- Thêm phòng
- Xóa phòng
- Đưa phòng vào bảo trì
- Mở lại phòng

## 4. Hiệu ứng

Website có:

- Loading
- Hover menu
- Active menu
- Smooth scrolling
- Ripple button
- Hover card
- Fade animation
- Modal animation
- Toast notification
- Back to top
- Form focus effect

## 5. Cài đặt

Cài Python 3.

Mở CMD tại thư mục project.

Chạy:

pip install -r requirements.txt

## 6. Chạy backend

python app.py

Backend:

http://127.0.0.1:5000

## 7. Chạy frontend

Mở:

index.html

trên trình duyệt.

## 8. Gmail

Tạo file:

.env

và thêm:

GMAIL_USER=your_email@gmail.com

GMAIL_APP_PASSWORD=your_app_password
